# 📚 LearnLog - 개발자를 위한 AI 검색 아카이브 시스템

[https://github.com/aengu/learn-log](https://github.com/aengu/learn-log)

[Learn Log - AI 개발 지식 베이스](https://learn-log.onrender.com/)

## 🎯 프로젝트 개요

개발 중 기술적 질문을 검색하면, AI가 답변과 공식 레퍼런스를 자동으로 찾아 마크다운으로 정리해주고, 저장된 학습 로그를 기반으로 간격 반복 연습문제를 자동 생성·채점하여 복습까지 이어지는 학습 아카이브 시스템입니다.

**핵심 가치**: 검색 → 정리 → 복습의 학습 루프를 하나의 시스템 안에서 완결

> 제가 개발하면서 매일 직접 쓰는 개인 학습 도구입니다. 토이 프로젝트로 끝내지 않고, 실제 사용 중 느낀 불편을 기능 개선으로 이어가고 있습니다.

## ✨ 주요 기능

### 1. **AI 기반 기술 질문 답변**

- 사용자가 입력한 개발 관련 질문에 대해 AI가 상세한 답변 제공
- 예: "docker bridge network와 host network 차이"

### 2. **공식 레퍼런스 자동 검색 및 발췌**

- 질문과 관련된 공식 문서 자동 검색
- 각 레퍼런스의 URL 및 핵심 내용 발췌

### 3. **노션 스타일 마크다운 자동 변환**

- AI 답변과 레퍼런스를 하나의 문서로 통합
- 표(table), 코드 블록, 하이라이트 등이 포함된 읽기 쉬운 포맷
- 노션에 바로 복사/붙여넣기 가능

### 4. **검색 히스토리 아카이빙**

- 모든 검색 내용을 게시판 형식으로 저장
- 태그/카테고리별 분류
- 검색 및 필터링 기능

### 5. **간격 반복 연습문제 시스템**

- 저장된 학습 로그를 정말 이해했는지 점검하기 위한 연습문제
- LLM이 두 유형(직접 답하기 / 선택지 고르기)으로 자동 생성
- 객관식은 정답 매칭, 서술형은 자가 마킹 체크리스트로 빠뜨린 핵심 포인트를 직접 확인
- 간격 반복 알고리즘(1, 3, 7, 14, 30일)으로 복습 스케줄 자동 관리 — 맞히면 간격이 늘어나고, 틀리면 1일로 리셋

## 🛠 기술 스택

### **Backend**

- **Django 5.x**: 웹 프레임워크
- **Django REST Framework**: API 엔드포인트 구현
- **PostgreSQL**: 검색 히스토리 및 메타데이터 저장, Full-Text Search

### **Frontend**

- **Django Template** + **HTMX**: SPA 없이 서버 렌더링 기반으로 SSE 스트리밍, 무한스크롤, 부분 페이지 갱신 구현
- **Tailwind CSS**: 유틸리티 클래스 기반 CSS 프레임워크

### **Testing & CI**

- **pytest** + **pytest-django**: 테스트 러너 및 Django 통합
- **factory_boy**: 테스트 데이터 팩토리
- **GitHub Actions**: push/PR 시 자동 테스트 실행

### **Deployment**

- **Docker** + **Docker Compose**: 컨테이너화 및 개발 환경 구성
- **Render**: 프로덕션 배포 (Web Service + Managed PostgreSQL)

## 🤖 AI/검색 LLM API

### **1. Tavily API** (웹 검색)

- **역할**: 실시간 웹 검색 및 공식 레퍼런스 발견
- **장점**:
    - AI 에이전트에 최적화된 검색 엔진
    - 무료 티어 제공
    - 특정 도메인(공식 문서) 우선 검색 가능
- **사용 사례**:
    - 질문 관련 공식 문서 URL 수집
    - 각 문서의 핵심 내용 발췌

### **2. Mistral API** (LLM — 답변 생성)

- **역할**: 기술 질문에 대한 상세 답변 생성
- **모델**: Mistral Large 3 (GPT-4o / Claude 3.5 Sonnet급)
- **장점**:
    - 개념 설명의 깊이, 코드 예시의 정확도, 한국어 표현의 자연스러움이 우수
    - 무료 티어 제공
- **사용 사례**:
    - 기술 질문에 대한 상세한 답변 생성

### **3. Groq API** (LLM — 경량 작업)

- **역할**: 태그 추출, 마크다운 변환 등 경량 작업
- **모델**: Llama 3.3 70B Versatile
- **장점**:
    - 무료 티어 (하루 14,400 요청)
    - 초고속 응답 속도
- **사용 사례**:
    - 태그 자동 추출
    - Tavily 검색 결과를 통합하여 노션 스타일 마크다운 생성

> 초기에는 Groq 단독 사용이었으나, 답변 품질 향상을 위해 Mistral Large를 도입하고 작업별로 분리하는 하이브리드 구조로 전환. → [[LLM 공급자 하이브리드 전환 - Groq + Mistral 속도·품질 벤치마크|상세 벤치마크]]

## 개발 후기

### 왜 만들었나

검색해서 저장만 하고 다시 안 보게 되는 문제가 있었습니다. 개발 중 모르는 걸 검색하면 그 순간엔 이해한 것 같은데, 며칠 지나면 같은 걸 또 검색하고 있었습니다.

"검색 → 정리 → 복습"이 한 곳에서 돌아가는 시스템이 필요했고, 그게 LearnLog를 만든 이유입니다.

### 실제로 쓰고 있나

다른 사용자를 위한 서비스가 아니라, **제가 개발하면서 매일 쓰는 개인 도구**입니다. 현재 제 학습 로그 61건, 연습문제 5회 시도, 정답률 40%. 꾸준히 사용하기 위해 Streak(연속 학습일수) 시스템과 GitHub 잔디 스타일 통계 대시보드도 직접 만들었습니다. → [[통계 대시보드 + Streak(불꽃) 시스템 구현|통계 대시보드 개발일지]]

정답률이 40%라는 건, 저장만 하고 넘어갔던 내용을 실제로는 제대로 이해하지 못했다는 뜻입니다. 이걸 숫자로 확인할 수 있게 된 것 자체가 이 프로젝트의 가장 큰 수확이었습니다.

### 아쉬운 점

- **무료 LLM 플랜의 속도 한계**: Mistral Large 무료 티어는 답변 품질은 좋지만, 답변 생성에 약 30초가 걸립니다. 유료 모델 대비 속도면에서 한계가 있습니다. → [[LLM 공급자 하이브리드 전환 - Groq + Mistral 속도·품질 벤치마크|속도·품질 벤치마크 상세]]
- **동기 처리 구조 개선**: 외부 API를 동기로 6번 호출하는 구조에서 병렬 호출 + 프롬프트 경량화 + 스트리밍으로 전환하여 응답 대기를 단축했습니다. → [[LLM 응답 속도 최적화 - 병렬화, 프롬프트 경량화, 스트리밍|상세]]
