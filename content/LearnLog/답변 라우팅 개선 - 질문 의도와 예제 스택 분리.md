# 답변 라우팅 개선 - 질문 의도와 예제 스택 분리

> SQL이나 프로토콜 질문에도 Django 코드가 붙던 문제를 줄이기 위해, 기존 라우터가 설명 중심과 예제 스택을 함께 선택하도록 했다. 스트리밍과 검색 흐름은 유지했다.

## 문제와 선택

기존 기본 지침은 코드 예제를 요구하고, 언어·스택 지정이 없으면 Python·Django를 기본으로 삼았다. 문구만 바꿔도 답변이 원하는 방향으로 안정적으로 나오지는 않았다.

그래서 답변 모델이 설명 방식까지 전부 결정하게 두는 대신, [[LangGraph 라우팅 에이전트 - 질문별 조건 분기|기존 라우터]]의 한 번의 호출에서 두 값을 추가로 선택하게 했다.

| 판단값 | 선택지 |
| --- | --- |
| `answer_focus` | concept / mechanism / implementation / comparison / troubleshooting / auto |
| `example_stack` | sql / python / django / auto |

설명 중심은 개념·동작 원리·구현·비교·문제 진단 중 **어디에 비중을 둘지** 정한다. 답변에 다른 종류의 설명을 넣지 못하게 제한하는 것은 아니다. 스택은 예제의 기술 범위를 정하며, `auto`는 특정 언어나 코드 예제를 강제하지 않는다.

## 동작

1. 라우터가 현재 질문·이전 대화·사용자 지침을 보고 두 값을 선택한다. 과거 기록에 Django 코드가 많다는 이유만으로 Django를 고르지 않도록 한다.
2. `SearchState`를 통해 선택값을 생성 단계로 전달한다.
3. 기존 Python·Django 강제 지침 대신 선택한 설명·예제 지침을 조립한다. 근거 관련 지침과 프롬프트 배치는 유지한다.
4. 기존 답변 모델이 스트리밍으로 생성한다. 잘못되거나 누락된 선택값은 `auto`로 처리한다.

사용자가 명시한 언어·스택은 자동 선택보다 우선한다. Java처럼 목록에 없는 언어는 `auto`로 두고 원래 요청을 따른다. SQL은 DBMS 지정이 없으면 PostgreSQL 기준임을 밝히도록 했다.

직접 수정한 사용자 프롬프트는 자동 지침보다 우선한다. 단, **편집란을 열어 기본 문구가 채워진 것만으로는 사용자 지침을 전송하지 않는다.** 비우거나 기본 문구로 되돌리면 자동 라우팅을 사용한다.

## 적용 전후 비교

대표 질문 6개에 대해 동일 질문·동일 검색 스냅샷·동일 생성 설정으로 각 조건을 1회 비교했다. 비교 답변은 DB에 저장하지 않았다.

| 질문 | 선택 | 관찰 |
| --- | --- | --- |
| 2PC가 뭐야? | concept / auto | Django 언급 9회 → 0회, 흐름·의사코드로 설명 |
| 중복 이메일 조회 SQL | implementation / sql | 섞여 나오던 Django 예제가 빠지고 SQL로 설명 |
| QuerySet 중복 조회 | implementation / django | Django ORM 예제 유지 |
| Python / Java 이진 탐색 | implementation / python 또는 auto | 각각 요청한 언어 유지 |
| Saga와 2PC 비교 | comparison / auto | Django 예제 없이 차이·선택 기준 중심으로 설명 |

스택 선택 유도에는 효과가 보였지만 일부 구현 답변은 더 길어졌다. 표본도 작으므로 **간결함·사실 정확도·속도가 개선됐다는 결론은 아니다.** 분당 토큰 제한과 재시도도 있어 생성 시간의 단순 비교는 피했다.

라우터 구현 후 전체 테스트 184개와 Ruff 검사가 통과했다. 프롬프트 편집 동작은 별도로 JavaScript 6개 상황을 확인했다.

## 남은 범위

이번 변경은 설명 방식 통제이며 환각 방어는 별개다. 공식 근거 확보와 주장·근거 대조는 후속 과제로 남겼다.

관련 구현: `search/services/learnlog_service.py`, `search_agent.py`, `search/templates/search/main.html`. 재현 스크립트는 `search/experiments/compare_answer_styles.py`다.
